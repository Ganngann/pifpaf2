## 2024-07-27 - Search Form Accessibility Improvements
**Learning:** Grouped inputs (like min/max price ranges or location/distance pairs) often lack explicit individual `<label>` tags, relying only on a shared visual header. This creates a significant accessibility gap for screen reader users who cannot associate the generic header with the specific input field.
**Action:** Always verify that every interactive element within a logically grouped layout possesses either an explicit `id`/`for` paired `<label>` or a descriptive `aria-label` attribute (e.g., `aria-label="Prix minimum"`) to ensure complete screen reader accessibility. Additionally, guarantee all interactive elements explicitly define clear Tailwind CSS focus states (`focus:ring-2 focus:ring-blue-500 ...`) to maintain robust keyboard navigation support.
