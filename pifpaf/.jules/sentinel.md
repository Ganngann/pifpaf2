## 2026-07-22 - Prevent IDOR in Route Model Binding without Authorization Checks
**Vulnerability:** Laravel route model binding implicitly loads models based on IDs passed in the URL (e.g., `DisputeController@create(Transaction $transaction)`), but it does not check if the currently authenticated user is authorized to interact with that specific model, leading to Insecure Direct Object Reference (IDOR) if an attacker alters the ID.
**Learning:** Even if a base controller implements or is expected to use authorization logic, individual controller actions that receive injected models must explicitly verify user permissions (e.g., via `Gate` checks or `$this->authorize()`) before processing the request or displaying sensitive data.
**Prevention:** Always pair route model binding with explicit authorization checks (`$this->authorize('action', $model)`) at the very beginning of the controller method, and ensure the base controller explicitly uses the `AuthorizesRequests` trait if it's not present by default.
