## 2026-05-16 - Add ARIA Labels to Navigation Elements
**Learning:** Icon-only links and toggle buttons (like the notifications bell and hamburger menu) are common in Laravel Breeze/Alpine navigation components but often lack accessible labels by default.
**Action:** When adding or reviewing icon-only interactive elements, ensure `aria-label` is present. For elements that toggle state (like dropdowns or mobile menus), bind `aria-expanded` to the state variable (e.g., `:aria-expanded="open.toString()"` in Alpine.js) to communicate state to screen readers.
## 2024-06-02 - Empty State for Purchases

**Learning:** When using the custom `x-ui.empty-state` component to replace unstyled paragraph tags in Laravel Blade, standard HTML elements (like `<a>` tags) within the `<x-slot name="actions">` must be manually styled using Tailwind CSS classes that mirror the design of a primary button, as the application's `<x-primary-button>` component only renders a `<button>` tag and does not natively support an `href` attribute. Also, you must not use or require any external icons (like from a CDN or library) unless they are already included in the project. If an icon is not readily available or cannot be easily mapped from the codebase without assumptions, it's safer to leave the icon out of the empty state component to avoid adding unnecessary dependencies or breaking styles.
**Action:** When creating empty states that require a Call-To-Action link to navigate users to other pages, always use an `<a>` tag and manually apply the Tailwind classes from `primary-button.blade.php`. Avoid using `<x-primary-button>` for navigation links. Furthermore, when designing empty states, avoid adding `icon` attributes unless an appropriate SVG exists in the project and can be sourced exactly.
